Use case: ui-mockup
Asset type: SelfMe Lab / Remote Agent Lab / compact service-management modal. User-approved visual reference (2026-10-10); illustrative UI, not implemented capability evidence.
Primary request: Design one practical small service-management panel as a modal over the supplied lightweight Remote Agent Lab index. This manages the two development deployments, not a general operations platform.
Input images: Image 1 is the new remote index, the exact backdrop and layout reference. Image 2 is the official brand mark; preserve its appearance in the background. Neither image is a request to redesign the index.
Composition: Straight 16:9 desktop screenshot. The remote index stays visible but dimmed behind one centered charcoal modal about 760px wide. Crisp fine grey border, small radius, minimal restrained cyan focus accent, no all-engine tint. Title "远端服务", close X on the right. Native Mac title strip remains visible; no global scrollbar.
Service controls: Two compact service rows, "OpenHands" and "OpenClaw", both illustrative "运行中" with green-dot status. Each has separate modest "停止" and "重启" buttons. A stopped service would replace these with "启动", not disable the engine entry. Below rows a small muted sentence "停止或重启会影响当前任务". No CPU, memory, container ids, exposed VNC ports, dependency tree or extra admin services.
Model connection: A restrained subsection "模型连接" with small peer tabs "OpenHands" selected and "OpenClaw". Four clean controls: "协议" dropdown displaying "OpenAI Compatible"; "Base URL" field showing "https://api.deepseek.com" as sample; "API Key" field masked with dots and a small visibility icon; "Model ID" field with placeholder "输入模型 ID". All controls neutral charcoal, readable white text, correctly aligned. This is a model-provider URL, not the Gateway endpoint. One brief capability note "桌面视觉操作需使用支持图像的模型". Controls allow later edits; no real secret or untested model-name promise.
Diagnostics: A compact collapsed "运行日志" row with a chevron, not a second terminal or admin dashboard. Footer "取消" and "保存连接" buttons, aligned consistently. Saving is distinct from restarting; do not imply a successful restart through a save label. Tiny "设计示意" in the screen corner.
Style: Match the reference near-black star shell, exact official brand, fine borders, precise Chinese sans-serif UI and restrained accent. Stars do not shine through the modal or text.
Constraints: No login form, tenant settings, accounts, billing, remote-host folder picker, local paths, actual keys, default YOLO grant, external shell, fake telemetry, mobile mockup or watermark.
Non-rendered boundaries: Default development auth is provisioned automatically. The local service lifecycle controller manages Docker deployments; a real remote deployment does not blindly receive Docker-host start/stop power from an end-user client. Provider configuration and authenticated engine state remain server-owned. Start/stop/restart outcomes and errors must be shown from actual health events. This is a visual review draft, not an API capability acceptance.
